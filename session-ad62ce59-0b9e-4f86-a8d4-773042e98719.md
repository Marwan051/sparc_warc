# Add BGE-M3 Cross-Encoder Reranking

## Summary

Add `BAAI/bge-reranker-v2-m3` as an online second-stage reranker:

```text
User/search query
    ↓
BGE-M3 query embedding
    ↓
PostgreSQL retrieves top 20 by cosine similarity
    ↓
Cross-encoder scores the 20 (query, chunk) pairs
    ↓
Keep best 5
    ↓
Evidence assembly and answer generation
```

The cross-encoder belongs in the `.venv-rag` query process, not the Spark embedding pipeline. Its score depends on a query and passage together, so it cannot be calculated permanently when corpus embeddings are created. BAAI documents the model as a multilingual reranker that returns one relevance logit per query–passage pair; applying sigmoid converts that logit to a 0–1 score without changing its order. [BAAI model card](https://huggingface.co/BAAI/bge-reranker-v2-m3)

Use the pinned INT8 ONNX conversion at commit `90213ffc6a8e6f051a6331269a0f5526cdd896f6`. Its model file is approximately 571 MB with SHA-256 `912fc1215c2dbff6499700534bd8d31253af01573861abbfc43afd1fab6cce5d`. [Pinned ONNX conversion](https://huggingface.co/onnx-community/bge-reranker-v2-m3-ONNX/commit/90213ffc6a8e6f051a6331269a0f5526cdd896f6)

```python

    pairs: list[tuple[str, str]],
```

```python
    ...
```

Purpose:

> Provide the public interface for scoring any number of pairs.

It should:

1. Return an empty one-dimensional array for no pairs.
2. Validate that every query and passage is a string.
3. Divide the pairs into groups of `config.batch_size`.
4. Call `_run_batch()` for each group.
5. Concatenate the raw logits in original input order.
6. Validate the combined count.
7. Apply `sigmoid()`.
8. Return one normalized score for every input pair.

Pseudocode:

```python
def score(self, pairs):
    if not pairs:
        return np.empty(0, dtype=np.float32)

    batches = []
    for start in range(0, len(pairs), self.config.batch_size):
        batch = pairs[start:start + self.config.batch_size]
        batches.append(self._run_batch(batch))

    logits = np.concatenate(batches)
    logits = validate_logits(logits, len(pairs))
    return sigmoid(logits)
```

`score()` is an orchestrator, but it remains short because tokenization, inference, validation, and normalization are separate functions.

def _positive_int(name: str, default: int) -> int:
    raw = os.environ.get(name, str(default))

    try:
        value = int(raw)
    except ValueError as error:
        raise ValueError(
            f"{name} must be an integer, got {raw!r}"
        ) from error

    if value < 1:
        raise ValueError(f"{name} must be at least 1, got {value}")

    return value


def sigmoid(logits: np.ndarray) -> np.ndarray:
    values = np.asarray(logits, dtype=np.float64)

    if not np.all(np.isfinite(values)):
        raise ValueError("reranker logits contain non-finite values")

    result = np.empty_like(values)
    positive = values >= 0

    result[positive] = 1.0 / (1.0 + np.exp(-values[positive]))

    exp_values = np.exp(values[~positive])
    result[~positive] = exp_values / (1.0 + exp_values)

    return result.astype(np.float32)

def validate_logits(logits:np.ndarray,expected_count:int) ->np.ndarray:
    values = np.asarray(logits,dtype=np.float32)
    if values.ndim == 2 and values.shape[1] == 1:
        values = values[:,0]

    if values.ndim != 1:
        raise ValueError(
        f"reranker output must contain one score per pair, got shape {values.shape}"
    )
    if len(values) != expected_count:
        raise ValueError(
        f"reranker returned {len(values)} scores "
        f"for {expected_count} input pairs"
    )

    
    if not np.all(np.isfinite(values)):
        raise ValueError("reranker returned a non-finite score")
    return values

        passages = [passage for _,passage in pairs]
        if self._tokenizer is None:
            raise RuntimeError("Reranker tokenizer was not initialized")
        tokens = self._tokenizer(queries,passages,padding=True,truncation=True,max_length=self.config.max_length,return_tensors="np")
        missing = self._input_names.difference(tokens)
        if missing:
            raise RuntimeError(
                "Tokenizer did not produce required reranker inputs: "
                f"{sorted(missing)}"
            )

        return {
            name: np.asarray(tokens[name])
            for name in self._input_names
        } 
    

    def _run_batch(self, pairs: list[tuple[str, str]]) -> np.ndarray:
        if not pairs:
            return np.empty(0,dtype=np.float32)

        self.ensure_loaded()

        if self._session is None or self._output_name is None:
            raise RuntimeError("Reranker was not initialized correctly")
        assert self._tokenizer is not None
        inputs= self._tokenize(pairs)

        with self._inference_lock:
            outputs = self._session.run([self._output_name],inputs)
            if len(outputs) != 1:
                raise RuntimeError(
                    f"Expected one reranker output, received {len(outputs)}"
                    )

            raw_logits = outputs[0]
            if not isinstance(raw_logits, np.ndarray):
                raise TypeError(
                    "Expected dense reranker logits, "
                    f"received {type(raw_logits).__name__}"
                    )
    
        return validate_logits(raw_logits, len(pairs))

# BGE-M3 Cross-Encoder Reranking — Simplified `SearchHit` Plan

## Flow

```text
embed_queries() -> search_candidates() -> build pairs
  -> reranker.score() -> validate -> assign in place
  -> sort + keep top_k per query -> assemble_evidence()
```

Rules:

* `similarity: float` stays cosine, never overwritten.
* `reranker_score: float | None = None`; `None` = not reranked, `0.0` is valid.
* Order is the mapping: pair `i` belongs to candidate `i`. No wrapper / copy / index struct.
* Validate count + finiteness **before** mutating any hit.
* Sort each query group independently.

```python
class OnnxReranker:
```

## 2. `retrieval/ranking.py` — order-based, in-place, no mapping struct

